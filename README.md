# Оценка стоимости квартиры

Проект представляет собой учебный ML-сервис для ориентировочной оценки стоимости квартиры по заданным параметрам.

Пользователь вводит характеристики квартиры, после чего приложение на Streamlit загружает заранее обученную модель и выдаёт прогноз цены.

---

## Демо

Сервис доступен по ссылке: https://2owbulnmrstrrfv3b3p5fs.streamlit.app

---

## Используемые признаки

В модели используются следующие признаки:

- район;
- площадь квартиры;
- количество комнат;
- удалённость от центра;
- этаж.

В рамках синтетического датасета район задаётся числом от 1 до 10: 1 — наиболее престижный район, 10 — наименее престижный.

---

## Описание данных

Датасет является синтетическим и содержит 1000 объектов недвижимости.

Каждая строка описывает одну квартиру:

| Признак | Описание |
|---|---|
| `район` | Класс района от 1 до 10, где 1 — наиболее престижный район |
| `площадь m^2` | Площадь квартиры в квадратных метрах |
| `кол-во комнат` | Количество комнат |
| `удаленность от центра (км)` | Расстояние до центра города в километрах |
| `этаж` | Этаж квартиры |
| `цена` | Сгенерированная стоимость квартиры в рублях |

При генерации данных заложена логика, близкая к реальной оценке недвижимости: цена зависит от площади, района, количества комнат, удалённости от центра и этажа. При этом площадь и район являются наиболее сильными факторами, а комнаты, этаж и расстояние до центра дают дополнительные поправки.

---

## Как работает проект

1. `scripts/generate_data.py` генерирует синтетический датасет квартир.
2. `scripts/train_model.py` обучает и сравнивает две модели машинного обучения:
   - `LinearRegression`;
   - `KNeighborsRegressor`.
3. Для KNN-регрессии автоматически подбирается количество соседей с помощью Leave-One-Out cross-validation.
4. Модели сравниваются по метрикам регрессии: `MAE`, `RMSE` и `R2`.
5. Лучшая модель выбирается по минимальному значению `RMSE`.
6. Итоговая модель сохраняется в файл `models/price_prediction_model.pkl`.
7. `app.py` запускает веб-интерфейс на Streamlit.
8. Пользователь вводит параметры квартиры и получает ориентировочную стоимость.

## Модель

В проекте решается задача регрессии, потому что необходимо предсказать конкретное числовое значение — стоимость квартиры в рублях.

Для сравнения используются две модели:

- `LinearRegression` — базовая линейная модель;
- `KNeighborsRegressor` — модель ближайших соседей для задачи регрессии.

Линейная регрессия используется как простой базовый вариант. Она помогает проверить, насколько хорошо стоимость квартиры можно описать линейной зависимостью от признаков.

KNN-регрессия работает по другому принципу: для новой квартиры модель ищет похожие объекты в датасете и рассчитывает цену на основе ближайших квартир. Для задачи оценки недвижимости это логично, потому что на практике стоимость часто определяют через сравнение с похожими объектами.

Так как KNN использует расстояния между объектами, в итоговой модели применяется `StandardScaler`. Масштабирование нужно, чтобы признаки с большими числовыми значениями, например площадь или расстояние до центра, не влияли на расчёт расстояний сильнее только из-за своего масштаба.

Для KNN было подобрано оптимальное количество соседей. По результатам Leave-One-Out cross-validation лучшим значением стало `k = 5`.

Итоговая модель сохраняется в файл `models/price_prediction_model.pkl`, после чего веб-приложение использует её без повторного обучения.

## Качество модели

Качество моделей оценивается по метрикам регрессии:

| Метрика | Что означает |
|---|---|
| `MAE` | Средняя абсолютная ошибка прогноза в рублях |
| `RMSE` | Ошибка прогноза, которая сильнее штрафует большие отклонения |
| `R2` | Доля зависимости цены, которую модель объясняет по признакам |

В проекте сравниваются:

- `LinearRegression`;
- `KNeighborsRegressor`.

Текущие результаты на тестовой выборке:

| Модель | MAE | RMSE | R2 |
|---|---:|---:|---:|
| Linear Regression | 1 475 560.59 | 1 958 889.42 | 0.9250 |
| KNN Regressor | 884 111.92 | 1 180 577.22 | 0.9728 |

По текущим метрикам KNN-регрессия показала меньшую ошибку и большее значение `R2`, поэтому она выбрана как итоговая модель.

Актуальные значения метрик автоматически записываются в файл:

```bash
reports/metrics.txt
```

## Запуск проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```

Сгенерировать данные:

```bash
python scripts/generate_data.py
```

Обучить модель:

```bash
python scripts/train_model.py
```

Построить графики:

```bash
python scripts/data_analysis.py
python scripts/visualizations.py
```

Запустить приложение:

```bash
python -m streamlit run app.py
```

Если используется macOS/Linux и команда `python` не работает, можно использовать:

```bash
python3 -m streamlit run app.py
```

## Ограничения модели

Модель обучена на синтетических данных, поэтому прогноз является ориентировочным.

Сервис не учитывает:

- год постройки дома;
- состояние квартиры и наличие ремонта;
- тип дома;
- близость к метро и инфраструктуре;
- юридические особенности объекта;
- реальные рыночные колебания.

Поэтому результат нельзя использовать как точную рыночную оценку. Проект является учебной демонстрацией полного ML-пайплайна: генерация данных, анализ, обучение модели, оценка качества и подключение модели к веб-приложению.
