# Оценка стоимости квартиры

Проект представляет собой ML-сервис для оценки ориентировочной стоимости квартиры по заданным параметрам.

---

## Используемые признаки

- класс района
- площадь квартиры
- количество комнат
- удалённость от центра
- этаж

---

## Описание данных

Датасет является синтетическим и содержит 1000 объектов недвижимости.

Каждая строка описывает одну квартиру:

| Признак | Описание |
|---|---|
| `район` | Класс района от 1 до 10, где 1 — наиболее престижный район |
| `площадь m^2` | Площадь квартиры в квадратных метрах |
| `кол-во комнат` | Количество комнат |
| `удаленность от центра (км)` | Расстояние до центра города в километрах |
| `этаж` | Этаж квартиры |
| `цена` | Сгенерированная стоимость квартиры в рублях |

---

## Как работает проект

1. `scripts/generate_data.py` генерирует синтетический датасет квартир.
2. `scripts/train_model.py` обучает и сравнивает две модели машинного обучения:
   - `LinearRegression`;
   - `KNeighborsRegressor`.
3. Для KNN используется фиксированное значение `n_neighbors=9` и параметр `weights="distance"`, что ускоряет обучение без заметной потери качества.
4. Лучшая модель выбирается по значению RMSE и сохраняется в файл `models/price_prediction_model.pkl`.
5. `app.py` запускает веб-интерфейс на Streamlit.
6. Пользователь вводит параметры квартиры и получает ориентировочную стоимость.

## Модель

В проекте решается задача регрессии: необходимо предсказать числовое значение — стоимость квартиры в рублях.

Для обучения и сравнения используются две модели машинного обучения:

- `LinearRegression` — базовая модель линейной регрессии;
- `KNeighborsRegressor` — модель на основе метода ближайших соседей для задачи регрессии.

Линейная регрессия используется как базовая модель, потому что она хорошо подходит для простого прогноза числовых значений и позволяет оценить зависимость цены от признаков квартиры.

KNN-регрессия используется как улучшенная модель. Её логика хорошо подходит для задачи оценки недвижимости: модель ищет похожие квартиры по площади, количеству комнат, району, удалённости от центра и этажу, а затем рассчитывает прогноз стоимости на основе ближайших объектов.

Для KNN дополнительно применяется `StandardScaler`, так как метод ближайших соседей использует расстояния между объектами. Масштабирование нужно, чтобы признаки с большими числовыми значениями, например площадь, не оказывали слишком сильное влияние на расстояние.

Для KNN используется фиксированное значение `n_neighbors=9` и параметр `weights="distance"`. Значение `k=9` было выбрано как удачный вариант по качеству прогноза. Отказ от автоматического подбора через Leave-One-Out cross-validation позволяет значительно ускорить обучение модели и сохранить близкое качество предсказаний.

После обучения модели сравниваются по метрикам MAE, RMSE и R². В файл `models/price_prediction_model.pkl` сохраняется модель с лучшим значением RMSE.

## Запуск проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```

Сгенерировать данные:

```bash
python scripts/generate_data.py
```

Обучить модель:

```bash
python scripts/train_model.py
```

Построить графики:

```bash
python scripts/data_analysis.py
python scripts/visualizations.py
```

Запустить приложение:
```bash
python3 -m streamlit run app.py
```

Если используется Windows или команда python3 недоступна:
```bash
python -m streamlit run app.py
```

## Качество модели

Для оценки качества использовались следующие метрики:

- MAE — средняя абсолютная ошибка в рублях;
- RMSE — среднеквадратичная ошибка;
- R² — коэффициент детерминации.

Модели оценивались на тестовой выборке размером 20% от датасета.

Для KNN использовались параметры `n_neighbors=9` и `weights="distance"`.

Результаты:

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 1 475 560.59 | 1 958 889.42 | 0.9250 |
| KNN Regressor | 883 614.41 | 1 172 221.92 | 0.9732 |

Лучшей моделью оказалась `KNN Regressor`, так как она показала меньшие значения MAE и RMSE, а также более высокий коэффициент R².

Именно KNN-модель сохраняется в файл `models/price_prediction_model.pkl` и используется в веб-приложении для прогноза стоимости квартиры.

## Ограничения модели

Модель обучена на синтетических данных, поэтому прогноз является ориентировочным.

Сервис не учитывает:

- год постройки дома;
- состояние квартиры и наличие ремонта;
- тип дома;
- близость к метро и инфраструктуре;
- юридические особенности объекта;
- реальные рыночные колебания.

Поэтому результат нельзя использовать как точную рыночную оценку, а только как учебную демонстрацию ML-сервиса.
