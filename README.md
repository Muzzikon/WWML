# Оценка стоимости квартиры

Проект представляет собой ML-сервис для оценки ориентировочной стоимости квартиры по заданным параметрам.

---

## Используемые признаки

- класс района
- площадь квартиры
- количество комнат
- удалённость от центра
- этаж

---

## Описание данных

Датасет является синтетическим и содержит 1000 объектов недвижимости.

Каждая строка описывает одну квартиру:

| Признак | Описание |
|---|---|
| `район` | Класс района от 1 до 10, где 1 — наиболее престижный район |
| `площадь m^2` | Площадь квартиры в квадратных метрах |
| `кол-во комнат` | Количество комнат |
| `удаленность от центра (км)` | Расстояние до центра города в километрах |
| `этаж` | Этаж квартиры |
| `цена` | Сгенерированная стоимость квартиры в рублях |

---

## Как работает проект

1. `scripts/generate_data.py` генерирует синтетический датасет квартир.
2. `scripts/train_model.py` обучает и сравнивает две модели машинного обучения:
   - `LinearRegression`;
   - `KNeighborsRegressor`.
3. Для KNN автоматически подбирается количество соседей через Leave-One-Out cross-validation.
4. Модели сравниваются по `Accuracy with scaling`, после чего лучшая модель сохраняется в файл `models/price_prediction_model.pkl`.
5. `app.py` запускает веб-интерфейс на Streamlit.
6. Пользователь вводит параметры квартиры и получает ориентировочную стоимость.

---

## Модель

В проекте решается задача регрессии: необходимо предсказать числовое значение — стоимость квартиры в рублях.

Для обучения и сравнения используются две модели машинного обучения:

- `LinearRegression` — базовая модель линейной регрессии;
- `KNeighborsRegressor` — модель на основе метода ближайших соседей для задачи регрессии.

Линейная регрессия используется как базовая модель. Она позволяет проверить, насколько хорошо простая линейная зависимость описывает связь между параметрами квартиры и её стоимостью.

KNN-регрессия используется как основная модель-кандидат. Её логика хорошо подходит для задачи оценки недвижимости: модель ищет похожие квартиры по площади, количеству комнат, району, удалённости от центра и этажу, а затем рассчитывает прогноз стоимости на основе ближайших объектов.

Для KNN дополнительно применяется `StandardScaler`, так как метод ближайших соседей использует расстояния между объектами. Масштабирование нужно, чтобы признаки с большими числовыми значениями, например площадь, не оказывали слишком сильное влияние на расстояние.

Количество соседей для KNN подбирается автоматически с помощью Leave-One-Out cross-validation. В результате работы скрипта определяется оптимальное значение `k` и минимальная LOO-ошибка.

После этого `LinearRegression` и `KNeighborsRegressor` сравниваются по показателю `Accuracy with scaling`. Этот показатель показывает долю прогнозов, в которых относительная ошибка не превышает допустимый порог после масштабирования признаков.

Лучшая модель сохраняется в файл `models/price_prediction_model.pkl` и используется веб-приложением для расчёта стоимости квартиры.

## Запуск проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```

Сгенерировать данные:

```bash
python scripts/generate_data.py
```

Обучить модель:

```bash
python scripts/train_model.py
```

Построить графики:

```bash
python scripts/data_analysis.py
python scripts/visualizations.py
```

Запустить приложение:
```bash
python3 -m streamlit run app.py
```

Если используется Windows или команда python3 недоступна:
```bash
python -m streamlit run app.py
```

## Качество модели

Качество модели оценивается по трём показателям:

| Показатель | Что означает |
|---|---|
| `Optimal k by Leave-One-Out` | Лучшее количество соседей для KNN, найденное с помощью Leave-One-Out cross-validation |
| `Minimum LOO error` | Минимальная средняя относительная ошибка при проверке Leave-One-Out |
| `Accuracy with scaling` | Доля прогнозов, где относительная ошибка не превышает 20%, после масштабирования признаков |

В проекте сравниваются две модели:

- `LinearRegression`;
- `KNeighborsRegressor`.

KNN использует масштабирование признаков через `StandardScaler`. Это важно, потому что метод ближайших соседей рассчитывает расстояния между объектами.

Актуальные значения метрик автоматически записываются в файл:

```bash
reports/metrics.txt
```

## Ограничения модели

Модель обучена на синтетических данных, поэтому прогноз является ориентировочным.

Сервис не учитывает:

- год постройки дома;
- состояние квартиры и наличие ремонта;
- тип дома;
- близость к метро и инфраструктуре;
- юридические особенности объекта;
- реальные рыночные колебания.

Поэтому результат нельзя использовать как точную рыночную оценку, а только как учебную демонстрацию ML-сервиса.
